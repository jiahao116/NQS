# Novelty check — 2026-11-22

**Question:** Has anyone simulated the mixed-dimensional (mixD) *trilayer* t∥-J∥-J⊥ model with NQS, or done a controlled 2D bilayer-vs-trilayer comparison?

**Verdict:** No such work found. Coverage is incomplete (web-search summaries only; direct arXiv API query not performed). Manual re-check required.
